# Панель тренера и аналитика

## Работа с командой

«Команда» показывает дневник за текущую местную дату каждого спортсмена, оценки самочувствия, симптомы, последнюю тренировку, RPE, нагрузку, состояние OnelapFit и предупреждения. Тренер может искать по имени, фильтровать по группе, доступу, дневнику и предупреждениям и сортировать результаты. Нагрузка относится к выбранному периоду. Дневник, предупреждения и последняя тренировка показывают текущее состояние. Пустые значения при сортировке идут после известных.

Карточка спортсмена содержит шесть вкладок — обзор, дневник, тренировки, аналитика, FTP и зоны, профиль. На обзоре доступны состояние и журнал OnelapFit, проверка подключения и ручной запуск синхронизации. Журнал из командной таблицы открывается сразу на обзоре. Из истории тренировок можно открыть отдельную тренировку и графики мощности, пульса и каденса. Графики доступны тренерам. Спортсмен сохраняет доступ к собственной числовой сводке.

Выберите 7, 28 или 90 дней либо диапазон до 366 календарных дней включительно. Относительный период завершается местной датой спортсмена. Timestamp тренировок переводится в часовой пояс текущего профиля. Даты анкет и снимки FTP и зон, использованные при расчёте импорта, сохраняются. Недели начинаются в понедельник. Первая и последняя недели обрезаются границами выбранного периода.

## Источники данных и пропуски

- Сводка анализирует сохранённые поля тренировок, расчёты `workout_metrics`, RPE, анкеты и датированные записи FTP. Источники общие с импортом FIT, карточкой тренировки и дневником.
- TSS и session-RPE суммируются отдельно. Рядом указано покрытие: сколько тренировок внесли значение в сумму. Ноль учитывается как измеренное значение. При отсутствии значений итог показывается как «Нет данных». Графики отдельных тренировок показывают причину пропуска из расчёта или источник недостающего значения.
- Динамика самочувствия сравнивает выбранную шкалу с индивидуальным уровнем. Для каждого дня это среднее за предыдущие 28 календарных дней, если есть хотя бы три анкеты. Анкета самого дня в сравнение не входит. Дни без анкеты остаются разрывами.
- FTP график держит последнее действовавшее значение до следующей записи. Для импорта FIT действует [правило сохранения снимка FTP](FIT_IMPORT.md). Зоны суммируются по имени и точным границам из снимка каждой тренировки. При смене границ зоны остаются отдельными интервалами. Интерфейс показывает время вне зон, время без показаний и причины отсутствия расчёта.
- Графики датчиков строятся из сохранённых временных рядов. Для длинных записей сервер сохраняет первую, последнюю, минимальную и максимальную точки интервала. При пропуске датчика или разрыве между измерениями больше двух секунд линии прерываются. Исходный ряд остаётся доступен через API карточки тренировки.
- Рендеринг графиков выполняется через Recharts. Графики загружаются при открытии нужной тренерской страницы. [Документация Recharts](https://recharts.github.io/en-US/api/ResponsiveContainer/)

## Предупреждения

Настройки общие для команды. Изменения выполняет тренер в разделе «Настроить предупреждения». Каждое правило можно включить или выключить. Значения хранятся в SQLite, правки отражаются в аудите. Текущий список предупреждений рассчитывается из актуального состояния данных при каждом запросе.

| Правило | Значение по умолчанию |
| --- | --- |
| Дневник пропущен | Анкеты за текущую местную дату нет к 10:00 по времени спортсмена. |
| Отмечены симптомы | В анкете спортсмен указал симптомы. |
| Высокая усталость | Общая усталость или усталость ног не ниже 4 из 5. |
| Мышечная болезненность | Оценка не ниже 4 из 5. |
| Низкая мотивация | Оценка не выше 2 из 5. |
| Отсутствует RPE | Нет оценки спустя 24 часа после окончания тренировки, начатой за последние 14 суток. При отсутствии полной длительности используются время таймера или время начала. |
| Ошибка синхронизации | Подключение требует повторной авторизации, подтверждения или имеет ошибку. Для команды без настроенного шлюза сигнал появляется только при сохранённой сессии. |
| Давно без тренировок | Прошло 7 местных календарных дней после последней тренировки или активации аккаунта, если тренировок ещё нет. |

Предупреждения показываются для активированных пользователей с действующим аккаунтом. Это сигналы для тренера по заполненным данным и состоянию сервиса. Они не являются медицинским диагнозом или прогнозом.

## API и проверка

Миграция `0005_coach` добавляет хранение порогов и выключателей правил. Новые маршруты доступны только тренерам в `/api/v1/analytics/team`, `/api/v1/analytics/athletes/{id}`, `/api/v1/analytics/athletes/{id}/overview`, `/api/v1/analytics/alert-settings` и `/api/v1/workouts/{id}/series`. Схемы и параметры опубликованы в локальном OpenAPI.

В тестах известные FIT проходят настоящий импорт и сверяются с аналитикой, карточкой и временным рядом. Дополнительно проверен импорт открытого файла Garmin с показаниями датчиков в отдельной временной базе. [Образец Garmin SDK](https://github.com/garmin/fit-python-sdk/blob/main/tests/fits/WithGearChangeData.fit)
