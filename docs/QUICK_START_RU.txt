CYCLING TEAM MONITOR
Простая инструкция для тренера

ПЕРВЫЙ ЗАПУСК НА WINDOWS

1. Один раз установите Python 3.13 и PowerShell 7.
   Python — https://www.python.org/downloads/windows/
   Найдите именно версию 3.13 и Windows installer (64-bit). В установщике
   отметьте «Add python.exe to PATH», чтобы Windows нашла программу.
   PowerShell — https://learn.microsoft.com/powershell/scripting/install/install-powershell-on-windows
   Для обычного 64-битного ПК выберите установщик Windows x64 MSI.
   Оставьте включённым добавление PowerShell в PATH.

2. Нажмите правой кнопкой мыши на ZIP и выберите «Извлечь всё».
   Распакуйте его в обычную локальную папку, например «Документы».
   Откройте распакованную папку. Файлы запускайте из неё.

3. Дважды нажмите Start.cmd. Для первой настройки нужен интернет.
   Когда появится запрос пароля, придумайте пароль для тестового тренера
   длиной от 12 символов. Введите его, нажмите Enter и повторите ввод.
   При наборе пароль на экране не отображается. Это нормально.
   Сохраните пароль в надёжном месте. Браузер откроется после настройки.

4. Введите почту coach@example.com и пароль, который только что задали.
   При следующих запусках новый пароль задавать не потребуется.

КАЖДЫЙ ДЕНЬ

• Start.cmd открывает приложение. Если вкладка уже открыта, обновите её.
  Можно также вручную открыть http://127.0.0.1:8000/login.
• Stop.cmd останавливает приложение. Сохранённые записи остаются на диске.
• Этот адрес работает на компьютере, где запущено приложение. Для работы
  с других устройств потребуется настройка общего адреса через HTTPS.

КАК ПОЛЬЗОВАТЬСЯ

Для тренера. Откройте «Управление доступом» → «Пригласить спортсмена».
Введите имя и почту. Отправьте полученную одноразовую ссылку спортсмену.
Для работы на другом устройстве приглашение создавайте после настройки
общего HTTPS-адреса. В разделе «Команда» откройте карточку спортсмена,
чтобы увидеть дневник, тренировки, RPE и аналитику.

Для спортсмена. Откройте приглашение и задайте свой пароль. Утром
заполните раздел «Дневник». После поездки загрузите файл .fit в разделе
«Тренировки». Откройте нужную тренировку и сохраните оценку трудности
RPE от 0 до 10. Для автоматической загрузки из OnelapFit потребуется
отдельно настроенная и проверенная интеграция. Пока используйте FIT.

ЕСЛИ НУЖНА ПОМОЩЬ

Если окно Start.cmd показывает ошибку, скопируйте текст сообщения
или сделайте снимок экрана без пароля и отправьте сопровождающему.
Сохраняйте папку data. В ней находятся база и загруженные тренировки.
Инструкции по копиям и настройке общего адреса находятся в папке docs.
