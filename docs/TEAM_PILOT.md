# Чек-лист испытаний на базе команды

Ведите журнал с моделью устройства, версией ОС и браузера, origin, датой, действием, ожиданием и результатом. Для диагностики используйте безопасные коды ошибок. Оставляйте персональные данные, GPS, ссылки активации и секреты внутри согласованного хранилища.

## Изолированная команда

Создайте тестовые данные в новом каталоге и задайте отдельный пароль только для этого стенда.

```powershell
.\.venv\Scripts\python.exe backend/tests/seed_team.py data/pilot-demo
```

Запустите в отдельном окне PowerShell, чтобы переменные стенда действовали только там.

```powershell
$env:CTM_DATABASE_PATH = Join-Path $PWD 'data/pilot-demo/team.sqlite3'
$env:CTM_FIT_PATH = Join-Path $PWD 'data/pilot-demo/fit'
$env:CTM_ALLOWED_ORIGINS = '["http://127.0.0.1:8010"]'
$env:CTM_SECURE_COOKIES = 'false'
$env:CTM_ONELAP_GATEWAY = ''
$env:CTM_ONELAP_KEYS = '[]'
.\scripts\server.ps1 start -Port 8010 -RunDirectory data/pilot-demo/run
```

Откройте [локальный стенд](http://127.0.0.1:8010). Аккаунты тренеров `coach01@example.com`–`coach03@example.com`, аккаунты спортсменов `athlete01@example.com`–`athlete20@example.com`. Дневники и FIT синтетические, аналитика использует штатный импорт. Различные состояния и история OnelapFit смоделированы для интерфейса, текущий статус без настроенного шлюза — «Недоступно». Для остановки используйте `.\scripts\server.ps1 stop -RunDirectory data/pilot-demo/run`.

## Провести испытания

- [ ] Чистая установка и миграции на целевом Windows-ноутбуке. Запуск, состояние, штатная остановка и перезапуск.
- [ ] Проверить HTTPS в LAN и отдельно разрешённый удалённый доступ. Использовать браузеры и сеть участников, убедиться в доверии сертификату, сроках сессии и работе одинакового адреса для приглашений.
- [ ] Установить PWA на Android, iPhone и Windows. Запустить с иконки, войти, открыть нужные разделы и установить обновление после сохранения форм.
- [ ] Пригласить спортсмена и тренера, активировать учётные записи, проверить однократность ссылки, сброс, выход, деактивацию и аудит. Подтвердить одинаковый охват команды для всех трёх тренеров и изоляцию спортсменов.
- [ ] Заполнить и исправить дневник за локальную дату, в том числе при разных поясах. Сверить статус тренерской панели и срабатывание предупреждений.
- [ ] Загрузить FIT с используемых велокомпьютеров с мощностью и без неё. Сверить время, паузы, расстояние и доступные датчики. Проверить дубликат, ошибку повреждённого файла, FTP по дате, NP, IF, TSS, зоны и RPE. Сверить графики с карточкой тренировки.
- [ ] Проверить исчезновение доступа во время выключения, затем восстановить работу. Для OnelapFit отдельно пройти [сценарии подлинного шлюза и аккаунта](ONELAPFIT_VALIDATION.md).
- [ ] Создать и проверить копию, восстановить в новый каталог и сверить вход, записи и оригиналы FIT. Проверить повторный вход и отзыв старых ссылок.
- [ ] Сверить все строки [отчёта о готовности](RELEASE_READINESS.md), закрыть открытые проверки и зафиксировать решение о начале эксплуатации.
